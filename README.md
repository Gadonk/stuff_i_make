This repository contains the files, configurations, modifications, and other projects I create for my 3D printer.

Its main purposes are:

* To keep an off-site backup in case my hard drive fails.
* To maintain a version history of my files.
* To make it easier to restore an earlier working version if something breaks.
* To keep my 3D-printer-related projects organized in one place.

The repository may include:

* Klipper configuration files and macros
* Happy Hare/MMU configuration
* Slicer profiles and settings
* Firmware-related files
* 3D models and printer modifications
* Documentation, notes, and troubleshooting information

## Important

These files are primarily made for my own hardware and printer setup. They may require changes before they will work correctly on another machine.

Always check pin assignments, movement limits, temperatures, hardware settings, and safety-related configuration before using anything from this repository.

Use these files at your own risk.
